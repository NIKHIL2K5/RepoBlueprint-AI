## 💡 The Problem Every Developer Faces
Every developer has had this moment: you get a flash of inspiration, grab a sheet of paper or whiteboard, sketch a few boxes and arrows, and then stall for days trying to figure out:
1. What tech stack fits best without over-engineering?
2. What are the free tiers vs production cloud costs?
3. What files, directories, and starter boilerplate code do I need to start writing real code?
4. Are there existing similar repositories on GitHub I can learn from or build upon?

**RepoBlueprint AI** bridges this gap as your **autonomous AI Technical Co-Founder**. It takes your napkin doodle, whiteboard photo, or 2-sentence prompt, conducts an architectural alignment interview, and generates an interactive system topology, cost estimate, live market intelligence, and a 1-click downloadable starter repo `.zip` with real working code.

## ✨ Features & Architecture

```
User Input (Napkin Canvas / Whiteboard Photo / Text / Link)
                     │
                     ▼
  PHASE 1: Multimodal Vision & Architecture Ingestion
    ├── High-DPI digital whiteboard drawing canvas
    ├── Multimodal spatial parsing of arrows & component boxes
    ├── Architectural component & data pipeline detection
    └── AI Co-Founder Alignment Interview (targeted decisions)
                     │
                     ▼
  PHASE 2: Master Architecture Blueprint Suite
    ├── 🌐 Interactive Mermaid.js Topology (Zoom, pan, copy code, SVG export)
    ├── ⚙️ Production Tech Stack (With trade-off alternatives)
    ├── 💰 Dynamic Cost Calculator (Interactive slider: 500 to 100k DAU)
    ├── 🔎 Market Intelligence (Live GitHub REST API search with stars & tags)
    ├── 📦 Starter Repo Scaffold (VS Code file explorer + 1-Click .zip download)
    └── ⏱️ Sprint Roadmap (Interactive 24h sprint milestone checkboxes)
```

## 🤖 3-Way Engine Flexibility
- **✨ Google Gemini / Gemma API**: Multimodal vision with automatic model fallback (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`).
- **🦙 100% Private Local Ollama**: Zero-cloud egress, on-device GPU inference (`gemma3:27b`, `llama3.3:70b`, `mistral:7b`) with Vite reverse proxy to prevent CORS issues.
- **🚀 Instant Demo Sandbox**: Zero-friction exploration mode for hackathon judges and visitors — explore the full pipeline with pre-computed production blueprints immediately without entering an API key.

## 🛠️ Quickstart

```bash
# 1. Clone repository
git clone https://github.com/satvik310706/repo-blueprint.git
cd repo-blueprint

# 2. Install dependencies
npm install

# 3. Launch dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
