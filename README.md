## 🎯 Executive Summary & The Problem

Every developer, founder, and hackathon team goes through the same painful bottleneck:

```
[ Inspiration ] ──► [ Doodle on Napkin / iPad ] ──► ❌ [ 3-5 Days of Architecture Paralysis ]
                                                           ├── Which database fits without over-engineering?
                                                           ├── What will hosting cost at 50k DAU?
                                                           ├── How do I write the docker-compose & boilerplate?
                                                           └── What open-source repos already solved this?
```

### 💥 The Core Pain Points
1. **The Blank Editor Stumble**: Turning spatial mental models (boxes, arrows, client-server flows) into code structure takes hours of repetitive boilerplate setup.
2. **Hidden Cloud Cost Traps**: Beginners and startups deploy architectures without knowing whether a serverless or VPS model costs $5/mo or $800/mo at scale.
3. **Language & Accessibility Barriers**: Most developer tooling forces English-only text prompts, shutting out builders who think best when speaking in their native language (Telugu, Hindi, Spanish, etc.).
4. **Cloud Privacy & Egress Concerns**: Enterprise ideas and private hackathon concepts cannot always be sent to third-party proprietary cloud APIs.

## ✨ Interactive Feature Deep Dive

### 1. 🎨 In-Browser Napkin Whiteboard Canvas
- **High-DPI Drawing Engine**: Fluid, responsive canvas with Pen, Component Box, Text/Label, Arrow connector, and Eraser tools.
- **Interactive Component Stamping**: Draw a box or click 1-click architecture stencils (`+ Web / Mobile UI`, `+ API Gateway`, `+ PostgreSQL DB`, `+ Redis Cache`, `+ AI / LLM Service`, `+ Auth / Security`) to stamp structured nodes instantly.
- **Text & Label Dialog**: Directly name boxes, assign subtitles, and select pre-suggested component types.
- **Photo Upload**: Drag-and-drop physical paper sketches, chalkboard photos, or iPad screenshots for computer vision processing.

### 2. 🎙️ Multilingual Real-Time Voice Dictation
- **8 Supported Languages**: Native Speech-to-Text and Text-to-Speech in:
  - 🇺🇸 English (`en-US`)
  - 🇮🇳 Telugu (`te-IN` — తెలుగు)
  - 🇮🇳 Hindi (`hi-IN` — हिन्दी)
  - 🇪🇸 Spanish (`es-ES` — Español)
  - 🇫🇷 French (`fr-FR` — Français)
  - 🇩🇪 German (`de-DE` — Deutsch)
  - 🇯🇵 Japanese (`ja-JP` — 日本語)
  - 🇨🇳 Chinese (`zh-CN` — 中文)
- **Live Web Audio API VU Spectrum**: Real-time `AudioContext` and `AnalyserNode` monitoring microphone decibels with visual "Voice Detected" feedback.
- **Continuous Auto-Restart**: Never disconnects during natural pauses while speaking your idea.
- **1-Click Spoken Templates**: Instantly populate localized architecture prompts in any supported language.

### 3. 🤖 Autonomous Multilingual Co-Founder Copilot
- **Live DOM Action Execution**: The Copilot does not just give advice; it interacts directly with your browser window:
  - Fills and refines your project ideas in real time.
  - Switches tabs and loads preset sample architectures.
  - Selects answers during the Technical Co-Founder Alignment interview.
  - Automatically triggers the starter repository `.zip` download.
- **Zero Raw JSON Leakage**: Engineered with a robust balanced-bracket parser and multi-line delimiter cleaners so conversation bubbles remain clean Markdown while actions appear as interactive cards.
- **Natural Voice Audio Output**: Speaks answers aloud in all 8 supported languages using sentence-boundary chunking that prevents HTTP 400 audio truncation.

### 4. 🤝 Phase 1: Technical Co-Founder Alignment
- **Detected Topology Summary**: Identifies frontend, backend, database, cache, and AI reasoning components.
- **Architectural Assumptions**: Flags unstated assumptions for founder review.
- **Smart Architectural Enhancements**: Suggests toggleable innovations (e.g., Edge Caching, Event-Driven Async Pipelines, AI Observability) with complexity ratings.
- **Quick Technical Decisions**: Interactive multiple-choice questions for databases, authentication, and deployment targets, with custom text overrides.

### 5. 🌐 Phase 2: Master Blueprint Dashboard Suite
- **Interactive Mermaid.js Topology**:
  - Live vector graph rendering that dynamically adapts to Light and Dark modes.
  - Interactive Zoom In, Zoom Out, Reset, and 1-click SVG / Mermaid code export.
- **Production Tech Stack Matrix**:
  - Recommended layers with trade-off alternatives and architectural justifications.
- **Interactive Cloud Hosting Cost Calculator**:
  - Real-time slider from 500 to 100,000 DAU estimating Compute (VPS/ECS), Database, Cache, and LLM Token bills.
  - Free Tier Launch Matrix showing zero-cost services (Supabase, Vercel, Upstash, Cloudflare Workers).
- **Live GitHub Market Intelligence**:
  - Direct integration with GitHub REST API searching relevant open-source repositories by topic with stars, forks, and licenses.
- **1-Click Starter Repo Generator**:
  - Interactive VS Code-style file tree viewer with syntax-highlighted previews (`README.md`, `docker-compose.yml`, `backend/main.py`, `frontend/package.json`, `.github/workflows/ci.yml`).
  - Client-side JSZip packaging that downloads a working, runnable repository bundle with zero server dependencies.
- **24-Hour Sprint Roadmap**:
  - Interactive milestone checklist tracking Phase 1 to Phase 4 development with real-time velocity metrics.

## 🤖 3-Way Resilient Engine Architecture

RepoBlueprint AI guarantees 100% uptime through a flexible three-tier engine architecture:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        REPOBLUEPRINT AI ENGINES                        │
├─────────────────────────┬─────────────────────────┬────────────────────┤
│ 1. 🦙 LOCAL OLLAMA      │ 2. ✨ GOOGLE GEMINI     │ 3. ⚡ SANDBOX DEMO │
│ • 100% Offline & Private│ • Gemma 4 / Gemini SDK  │ • Zero API key     │
│ • Zero Cloud Egress     │ • Multimodal Vision     │ • Instant judge    │
│ • GPU Acceleration      │ • Dynamic Schema Mode   │   evaluation       │
│ • llama3.2:3b / gemma3  │ • Automatic Fallbacks   │ • Pre-computed     │
│   via Vite Proxy        │                         │   architectures    │
└─────────────────────────┴─────────────────────────┴────────────────────┘
```

1. **Local Ollama**: Connects to `http://localhost:11434` with automatic model discovery (`llama3.2:3b`, `gemma3:27b`, `mistral:7b`). All prompts and sketches stay entirely on your device.
2. **Google Gemini & Gemma API**: Direct multimodal vision ingestion parsing spatial component boxes and connections with fallback chains (`gemini-2.5-flash` → `gemini-2.0-flash` → `gemini-1.5-flash`).
3. **Instant Demo Mode**: Evaluators and hackathon judges can explore the full user journey without providing API keys or installing Ollama.

## 🚀 Quickstart & Setup

### Prerequisites
- Node.js 18+ and npm
- *(Optional for offline mode)* [Ollama](https://ollama.com/) running with `ollama pull llama3.2:3b`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/satvik310706/repo-blueprint.git
cd repo-blueprint

# 2. Install dependencies
npm install

# 3. Launch development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Recommended Ollama Setup (100% Private Offline Mode)
```bash
# Install and run llama3.2:3b
ollama run llama3.2:3b
```
The application automatically routes Ollama requests through Vite's local reverse proxy to eliminate CORS restrictions.
